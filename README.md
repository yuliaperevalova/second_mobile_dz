## Тема приложения
Калькулятор для разделения счёта между несколькими людьми

## Описание
Офлайн-приложение на Jetpack Compose для расчёта суммы с каждого человека при разделении общего счёта.

## Функциональность
- **Экран приветствия (Home)** - название приложения и кнопки для начала работы
- **Экран ввода (Input)** - поля для ввода суммы счёта и количества людей с валидацией
- **Экран результата (Result)** - отображение результата расчёта с возможностью вернуться к редактированию или начать новый расчёт
- **Экран истории (History)** - просмотр последних 5 расчётов с возможностью открыть любой из них
- Сохранение введённых значений при возврате к редактированию
- Навигация между всеми экранами с любого места приложения

## Технологии
- Kotlin
- Jetpack Compose
- Material Design 3
- ViewModel (для управления состоянием)
- Navigation Compose (для навигации между экранами)
- StateFlow (для реактивного управления данными)

```
app/src/main/java/com/example/second_dz/

│   ├── screens/ - экраны приложения
│   │   ├── HomeScreen.kt - экран приветствия

│   │   ├── ResultScreen.kt - экран результата расчёта
│   │   └── HistoryScreen.kt - экран истории расчётов

│   └── theme/ - тема приложения

│       └── Type.kt
```
